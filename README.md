# Physics Low Temperature Labs
## Overview 
This folder contains the code for each weeks low temperature labs.
- Week 2: Aerogel resonance to find the normal fraction of superfluid He-II
- Week 3: Cryostat design: investigating materials and design to design a valid cryostat insert.
- Week 4: Second sound- finding the velocity of second sound as a function of temperature in He-II.

## Setup
To run, download the repository, setup the virtual environment with:
```bash
python -m venv .venv 

.venv/Scripts/activate

pip install -r requirements.txt
```
and then run whichever file you need to in the directory.
